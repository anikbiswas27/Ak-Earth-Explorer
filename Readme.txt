# 🚀 Overview

Earth Explorer Maps is a modern, lightweight, and feature-rich web mapping application inspired by Google Maps.

The project provides smooth navigation, progressive zoom, detailed map exploration, intelligent search, reverse geocoding, and rich location information using completely free and open-source services.

Unlike traditional map viewers, the application focuses on performance, clean UI, and detailed geographical information while relying entirely on free APIs.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/earth-explorer-maps.git
```

Open the project

```bash
cd earth-explorer-maps
```

Run locally

```bash
# Open index.html

or

python -m http.server

or

VS Code Live Server
```
